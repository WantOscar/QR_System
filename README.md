# QR_System

TIG KOREA 기술1팀 **납품 장비 이력 관리 시범 웹**입니다.

## 현재 시범 구조

같은 시범 장비 20대를 두 가지 방식으로 탐색할 수 있습니다.

### 1. 고객사 / 업체별
`고객사·업체 → 지사/관리그룹 → 현장 → 장비 → 장비 상세`

### 2. 제조사별
`제조사 → 모델 → 장비 → 장비 상세`

시범 제조사는 아래 3개입니다.
- 퓨쳐시스템 10대
- 시스코 5대
- 넥스지 5대

시범 데이터는 `TIG_전체장비_20260916.xlsx`에서 선별했습니다.

## 장비 상세 화면
- 장비 기본 정보
- 납품 / 점검 / 수리 이력
- 장비 / 현장 사진 영역
- 제조사별 자가 진단 / 간단 조치 가이드
- 장비 전용 QR
- 휴대폰 화면 열기
- QR 저장
- 전용 링크 복사
- QR 인쇄
